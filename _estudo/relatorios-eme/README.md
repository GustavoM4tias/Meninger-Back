# Relatórios da Eme

Relatórios customizados gerados por IA no Office: admin conversa com a Eme, ela busca dados reais via tools, monta o relatório por blocos padronizados (padrão visual do relatório do Ingá), preview ao vivo com ajustes iterativos, publish com versões, e compartilhamento privado/interno/público com URL tokenizada.

- Referência visual do padrão: `referencia-relatorio-inga.html`
